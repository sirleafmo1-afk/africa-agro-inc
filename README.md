# Africa Agro Inc - Website

Official website for Africa Agro Inc - Agricultural Solutions and Services

## Project Structure

This project includes two versions:

### 1. **Next.js Version** (Modern, Full-Featured)
- Located in root directory
- Modern React framework with server-side rendering
- Best for SEO and scalability
- Ideal for e-commerce integration

**Setup:**
```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

### 2. **HTML/CSS/JavaScript Version** (Simple, Lightweight)
- Located in `html-version/` directory
- Pure HTML, CSS, and JavaScript
- No build process needed
- Perfect for quick deployment

**Setup:**
```bash
# Just open html-version/index.html in your browser
# Or use a simple HTTP server:
python -m http.server 8000
```

Visit `http://localhost:8000/html-version/`
